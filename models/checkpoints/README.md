# مدل‌های تصویر

فایل `dreamshaper_8.safetensors`، checkpoint مدل DreamShaper 8 نسخهٔ ۸ (SD 1.5، FP16) از [Civitai](https://civitai.com/models/4384/dreamshaper?modelVersionId=128713) است. حجم دانلود حدود ۲٫۰ گیگابایت و SHA-256 آن `879db523c30d3b9017143d56705015e15a2cb5628762c11d086fed9538abd7fd` است. این فایل حجیم است و عمداً در Git نادیده گرفته می‌شود.

ComfyUI را با مسیر پوشهٔ `models` این پروژه در `extra_model_paths.yaml` تنظیم کنید تا مدل در فهرست checkpointها نمایان شود.
